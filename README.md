# SNAP — School Delivery Discovery (Summit Academy)

Login-gated discovery fact-find + route footprint for the four Summit Academy
schools (Youngstown & Warren, OH). No pricing — capture only.

- Discovery matrix: contact, weekly schedule, delivery window, access notes,
  closure dates, holiday breaks, holiday delivery plan — per school.
- Route visual: depot (2275 E 55th St, Cleveland) round-trip, per-leg + total
  drive time (live OSRM), 20 min/stop, weekly rollups.
- Gate + capture log reuse the shared SupplyNow Apps Script endpoint (SITE=summit).

Single self-contained `index.html`. `.nojekyll` required for GitHub Pages.
